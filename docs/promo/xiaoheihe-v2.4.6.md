## 推荐标题

**我把官匹 Demo 下载、2D 复盘、玩家评价和灵敏度测试做进了一个本地 CS2 工具**

备选：

- 官匹回放“已过期”之后，我做了一个本地 CS2 Demo 工作台
- 不装 PostgreSQL：一个集 Demo 下载、复盘、训练与剪辑于一体的 CS2 工具

## 正文

最开始，我只是遇到了一个很具体的问题：CS2 客户端里显示官匹比赛回放已经过期，但右下角还能复制出 `steam://rungame/730/.../+csgo_download_match` 这样的分享链接。普通下载器不认识它，已有 Demo 管理工具又需要额外安装 PostgreSQL。于是我想，能不能做一个更轻、更本地化，而且从下载到复盘都在同一个界面里的工具？

这就是 **MaxGameStudio**。它使用本地 SQLite 保存数据，不要求用户单独部署 PostgreSQL。项目目前免费开源，数据默认留在电脑本地。

> 配图 1：上手指南或官匹 Demo 下载（`getting-started.png` / `official-demo-download.png`）

### 从官匹 Demo 链接到本地资料库

软件可以接收 CS2 分享出来的官匹比赛链接，管理本地 Demo，并监听常用下载目录。比赛解析完成后，默认先打开我最想看的计分板：比分、K/D/A、ADR、KAST、爆头率、首杀、AWP 击杀和道具伤害集中在一页，同时给每名玩家生成 S–D 评级、优势和下一步优化方向。

解析结果会写入本地历史记录。关掉软件再回来，可以直接重新打开已经分析过的比赛，不需要为了看旧对局再完整解析一次。

### 2D 回放不再只是“看点在动”

2D 回放按回合展示双方站位、移动轨迹、击杀连线、射击、投掷物以及烟火区域。左右阵容里的玩家 ID 和地图标记都可以点击；选中后，阵容卡片、地图标记和评价区域会同步高亮。

复盘战术时还可以切换“全局 / 仅 A 队 / 仅 B 队”，快速隐藏另一队的位置、轨迹、弹道和投掷物。这里需要说明：它是一个透明的单队复盘筛选器，不是假装还原游戏内真实遮挡和几何视线的“战争迷雾”。

回合结束后，软件会根据击杀、死亡、首杀、爆头和下包/拆包事件评价本回合的全部玩家。你不仅能知道谁拿了人头，也能看到谁过早出局、谁完成有效贡献、谁制造了高影响回合。

### 不只复盘：灵敏度、磁轴和本地 CFG

灵敏度实验室内置无需点击的甩枪与连续跟枪测试，会结合 DPI、游戏灵敏度和分辨率判断当前速度偏快、偏慢还是较均衡，并给出可以直接粘贴进 CS2 的 `sensitivity` 数值、调整百分比和复测范围。

它也可以只读识别本地 Steam 账号及 CS2 CFG，预填游戏灵敏度、分辨率和画面比例。DPI 与显卡缩放仍会要求用户自己确认，软件不会偷偷修改 CFG。

磁轴输入实验室会检测重复触发、按住抖动、A/D 重叠和换向延迟，再给出触发行程与 RT 按下/抬起的建议起点。为了避免误导，建议采用小步调整和重复测试；Snap Tap、SOCD、LKP 等自动反向输入功能不建议在 CS2 官匹中开启。

### 从高光到成片

Demo 解析出的多杀、残局、首杀和其他片段可以加入 OBS 录制队列，再进入合辑工作台或 LiteCut 做简单整理。目标不是代替专业剪辑软件，而是把“找片段—录制—粗剪”这条 CS2 工作流尽量接起来。

### 关于速度、隐私和下载

第一次打开某场比赛的 2D 回放会额外生成整场轨迹与烟火缓存，所以会比再次打开慢；缓存命中后会直接读取本地结果。软件不会注入 CS2，也不提供作弊功能，主要读取 Demo 与用户明确选择的本地配置。

项目地址与最新版下载：

- GitHub：<https://github.com/INEEDBUG/MaxGameStudio>
- Release：<https://github.com/INEEDBUG/MaxGameStudio/releases/latest>

Windows 用户下载 Release 里的 `MaxGameStudio_*_x64-setup.exe` 即可，其他文件如果存在通常是校验或开发资产。项目仍在持续迭代，遇到 Demo 兼容性、地图资源或数据评价问题，欢迎带上脱敏后的日志在 GitHub 提 Issue。

最后也感谢本项目使用的开源组件与参考项目。这个软件是在真实使用问题中一点点长出来的，希望它能让大家少折腾环境，多花时间复盘真正值得看的回合。
