# MaxGameStudio 3.1.3

## Highlights

- Adds an independently controlled RESG window for **Hextech ARAM only**, following the selected champion and bench swaps. OP.GG remains independently configurable.
- Switch between the original **All data** page and remembered **Popular picks**: up to three augments per tier by sample count, and three equipment combinations per build stage by adoption rate. Win rates and sample sizes remain visible.
- Closing the League workspace can now **hide it to the Windows system tray**, instead of minimizing to the taskbar. Click the tray icon to restore it. Return-to-host, cancellation, and remembered close preferences remain available.
- Compact view supports light/dark themes and falls back to the original website when the page format is unsupported. Remote pages remain sandboxed without application IPC or Node.js access.

## 中文更新说明

### 海克斯大乱斗数据窗口

- 在窗口管理中单独启用或关闭 RESG，和 OP.GG 互不影响；仅海克斯大乱斗跟随当前英雄，换选后同步更新。
- 顶部可切换“全部数据 / 常用精选”，自动记住选择，随时可恢复完整页面。
- 精选按白银、黄金、棱彩各展示最多 3 项热门海克斯，装备按各出装阶段的采用率展示前 3 项；保留名称、图标、胜率和样本量。
- 原站海克斯列表未提供选取率百分比，因此按场次排序，不伪造百分比；热门不等于最高胜率。
- 手动关闭后不会因换英雄反复弹出；普通大乱斗和其他模式不启用此窗口。

### 系统托盘

- 工作台关闭弹窗明确显示“隐藏到系统托盘”，不再缩到任务栏。
- 点击托盘图标或托盘菜单可恢复工作台；保留“返回 MaxGameStudio”、取消以及可清除的记住选项。
- 预热阶段不创建工作台托盘图标；退出时释放图标。

### 验证与限制

- 本地功能验证包括 39 项窗口逻辑测试、7 项页面数据 fixture 测试、10 项宿主关闭/预热测试，以及隔离的 Windows 原生托盘与真实网站检查；用户已完成本地体验并批准发布。
- RESG 数据和可用性由第三方网站决定，加载速度受网络影响；页面格式变化时可能回退到完整页面或提示重试。未保证第三方网站永久兼容。
- 本版本不更改已有存储位置，不执行用户数据迁移。首次未预热启动仍可能需要数秒。
- 可从 3.1.2 直接升级；仍需用户点击“立即更新”才进入更新流程。

Required third-party notices are retained in the installer. Repository licensing is unchanged.
