# 英雄联盟工具箱 1.0.0-beta.2

- 安装向导可以选择“为所有用户安装”。正常双击安装包，选中该项并继续后，Windows 会请求管理员权限。
- 安装范围、提权失败和取消提示使用简体中文；系统权限窗口跟随 Windows 显示语言。
- 全用户模式共享程序，各 Windows 账户分别保留自己的工具箱设置和数据库。覆盖安装与卸载保留个人数据。
- 继续通过独立工具箱更新通道检查新版本。MaxGameStudio 主程序的 Release 不会触发工具箱更新。

升级前请关闭工具箱。安装器会保留旧目录中的未知文件和已修改的文件。若手动以管理员身份启动安装器，个人数据位置的选择推迟到正常启动后，旧个人版保留为恢复来源，向导会给出中文提示；通常直接双击即可，由安装器在需要时申请权限。
