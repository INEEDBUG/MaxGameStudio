## Highlights

- Python starts on demand for service-dependent pages, rather than on every application launch. Home, update checks and the embedded League entry no longer wait for Python.
- Backend startup errors stay on the affected page instead of closing the application. Returning from the League workspace no longer waits for Python startup.
- RESG adds a remembered **Keep on top** toggle in its own toolbar and window settings.
- GitHub update checks have bounded timeouts and clearer failure handling. Cancelling a download prevents installation; an in-flight native request may take time to finish.

## 中文更新说明

- 后端改为按需启动：首页、检查更新和英雄联盟入口不再等待 Python；CS2、无畏契约等依赖后端的页面首次使用时才启动服务。

## Limits

- Service-dependent settings pages still start Python. First use of backend features still requires service startup.
- GitHub and RESG availability remain network-dependent; this version does not promise faster downloads in mainland China.
- Download cancellation prevents installation, but does not immediately abort the native network request.
- Required third-party notices and existing licensing are retained.
