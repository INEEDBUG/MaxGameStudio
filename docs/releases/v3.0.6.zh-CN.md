# MaxGameStudio 3.0.6 历史本地候选（未发布）

> **该版本从未发布。** `v3.0.6` 只是历史本地候选，已由正式稳定版 `v3.1.0` 取代。本文保留作历史记录，不对应 GitHub Release、正式更新清单或可供现有用户升级的安装包。

本版本集中修复英雄联盟 Mini、秒退与实时对局体验，并为 VALORANT 真拉伸补充可恢复的手动 CFG 选择。

## 英雄联盟 Mini

- 置顶按钮现在可以正常取消置顶；保存期间到达的旧状态不会再把用户选择反向覆盖。
- Mini 内新增透明度滑块，设置会持久化；最低透明度限制为 40%，避免误操作后窗口完全不可见。
- 秒退改为 Mini 内联二次确认，不再要求输入确认文字。
- 秒退请求返回后还会读取新的 Gameflow 阶段与 ChampSelect 会话；只有确认选人会话已经结束才报告成功。
- 如果客户端暂未确认退出，界面会显示明确错误并允许取消仍在运行的重试。秒退会产生游戏处罚，请只在理解后果时操作。

## 英雄联盟实时对局

- 应用启动时提前创建隐藏的实时对局 WebView，并在 React 深色首帧准备完成后才允许显示，减少游戏中弹出白窗。
- 进入 `GameStart`、`InProgress` 或 `Reconnect` 阶段自动显示独立实时对局窗口；离开实时阶段或断开客户端后自动隐藏。
- 自动显示独立窗口不依赖“主窗口自动切换到实时对局页”设置，二者职责分离。
- 后端先返回当前阵容快照，再逐名发布已完成的玩家战绩；前端在短暂渐进阶段以 300 ms 读取本机缓存，完成后恢复 5 秒常规刷新。
- 新对局或阶段切换时会取消旧的后台补全任务，避免旧结果覆盖当前阵容。

## 客户端工具箱精简

- 移除游戏内发送界面及其全局发送快捷键管理器。
- 移除房间工具、无尽狂潮工具、本地玩家标签批量管理和 League 设置迁移界面。
- 保留玩家中心中的单个玩家备注，以及仍在使用的兼容后端接口；不会删除已有本地数据。

## VALORANT 真拉伸

- 自动发现失败时会区分配置根目录不存在、尚未生成账号配置、Windows 配置目录缺失、文件无效或目录不可读。
- 在现有“无畏契约 → 真拉伸”页面内新增“手动选择配置文件”和“重新检测”，没有新增路由或大型管理器。
- 仅接受 `%LOCALAPPDATA%\\VALORANT\\Saved\\Config\\<profile>\\Windows*\\GameUserSettings.ini` 下的真实配置文件；错误路径会被拒绝并显示原因。
- 手动选择的路径会在本次页面会话中用于检测、应用、只读锁定、解锁和备份恢复；显示模式应用失败时也会恢复同一账号的备份，不会误恢复其他 profile。

## 验证边界

- 自动化测试不会对真实 LCU 执行秒退，也不会修改开发机器的真实 VALORANT 配置。
- 发布前会使用项目测试、前端生产构建、Rust/Windows 构建工作流及本机安装包进行验证；真实游戏阶段仍受 Riot/LCU 版本和本机环境影响。
