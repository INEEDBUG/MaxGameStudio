# MaxGameStudio 3.0.1

## 重要版本说明

版本 `2.5.17` 已撤回。该版本存在重大升级缺陷：旧 Tauri 卸载程序缺失时可能中止安装；自动更新还缺少可靠的“跳过此版本”行为，并存在版本边界竞态。

- 已安装 `2.5.17` 的用户：请升级到 `3.0.1`。
- 尚未升级的用户：请继续使用 `2.5.16`，不要安装或继续分发 `2.5.17`。

## 3.0.1 修复

- 安全清理精确匹配的失效卸载注册项，不误删其他应用的注册项。
- 升级清理不会删除用户数据或数据目录。
- 自动更新支持跳过当前版本，并修复版本边界竞态。
- 强制更新不可跳过，避免客户端停留在不兼容版本。
- Release 标题固定使用纯版本号，避免标题格式影响版本识别。

实际安装包、签名状态和发布状态以对应 GitHub Release 页面为准。
