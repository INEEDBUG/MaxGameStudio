# MaxGameStudio 3.2.0-beta.2

本次测试版更新安装流程，主程序和英雄联盟工具箱仍独立安装、独立更新。

- 安装向导可选择“仅为我安装”或“为所有用户安装”。选择全用户后继续时，才向 Windows 申请管理员权限。
- 安装器的选项、权限失败和取消提示使用简体中文。Windows 自己的权限确认窗口使用系统显示语言。
- 全用户安装共享程序文件，各 Windows 账户仍使用自己的数据位置。已有配置、数据库和 Steam 账户信息继续保留；更换数据目录仍保留源数据。
- 个人版升级到全用户版时，在安装成功后处理原用户的程序注册和快捷方式，避免继续打开旧版本。未知文件与个人数据不作为安装垃圾删除。

独立工具箱使用 `league-v1.0.0-beta.2` 标签，仅通过工具箱自己的更新通道推送。主程序的更新不会触发工具箱更新。

建议正常双击安装包，由安装器在需要时申请权限。手动以管理员身份启动时，个人数据位置的选择推迟到该用户正常启动后，旧个人版保留为恢复来源，向导会给出中文提示。

开发机没有 Steam 和英雄联盟客户端。本次验收聚焦安装、覆盖升级、存储位置、两个产品的更新边界与卸载保留数据；真实游戏登录与对局仍需要在装有游戏的电脑上测试。
