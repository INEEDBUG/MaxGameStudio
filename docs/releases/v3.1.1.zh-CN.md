# MaxGameStudio 3.1.1

> **正式稳定版。** `v3.1.1` 是 `v3.1.0` 的维护更新，重点修复内嵌英雄联盟工作台右上角关闭按钮的交互问题。正式安装包与在线更新清单以本仓库稳定版 CI 生成并签名的文件为准。

## 内嵌英雄联盟工作台关闭流程

- 点击工作台右上角 `X` 后，不再直接返回 MaxGameStudio。
- 现在会明确询问用户：**返回 MaxGameStudio**，或**最小化英雄联盟工作台**并保留其运行状态。
- 点击取消会保留当前工作台和宿主状态，不会意外关闭窗口、终止后台任务或结束游戏进程。
- “节省内存”和“后台并行”两种启动方式使用一致的关闭确认规则：前者仍可在工作台结束后恢复主 WebView 与后端，后者继续保留主程序并行运行。
- 关闭选择不会覆盖用户已经记住的启动方式；如果在关闭确认框中勾选“记住选择”，只会记住工作台的关闭动作，之后仍可在工作台设置中改回“每次询问”。需要改变自动进入方式时，仍可在英雄联盟工作台入口重新选择或清除记忆。

## 安全边界

- 本版本不结束英雄联盟、CS2 或 VALORANT 游戏进程，不停止 Vanguard，也不修改游戏内存或游戏文件。
- 关闭确认仅控制 MaxGameStudio 宿主和内嵌工作台的窗口/运行时生命周期。
- 正式更新仍要求 Tauri updater 签名；安装包版本、内置后端版本和更新清单必须统一为 `3.1.1`。

## 升级说明

- `v3.1.0` 用户可以直接升级到 `v3.1.1`，不需要安装中间版本。
- `v2.5.17` 已撤回，`v3.0.6` 从未进入正式 Release 或更新通道；它们不会成为升级前置版本。
- 测试候选使用带预发布后缀的版本号（例如 `3.1.1-rc.1`），不会进入正式 GitHub Release 或 `updater/latest.json`。
