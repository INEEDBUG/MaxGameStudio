# MaxGameStudio 3.0.4

本版本继续集中改进英雄联盟板块：实时对局拥有独立入口和渐进加载，组排与胜率队判断更严格；Mini 自动接受改为持续事件监听，浅色模式下的玩家指标也恢复可读。同时新增四种区域语言选项并修复游戏分区无法手动收起的问题。

## 英雄联盟实时对局

- `/league/ongoing` 改为独立页面，直接提供刷新、实时设置和独立窗口入口，不再套用大型自动化页面。
- 首屏先返回队伍和玩家卡片，战绩分析按玩家渐进补齐；单个玩家数据较慢时不再阻塞整页。
- 部分结果仅进行有界快速刷新，完整后恢复到常规五秒周期；页面卸载和历史预览会停止实时请求。
- 组排识别改为候选组内任意两名玩家都满足共同对局阈值，避免链式关系误合并。
- 胜率队与败率队判断排除未知结果，并保留样本数、胜率和阈值证据。
- 修复浅色模式下玩家胜率、KDA 与 Akari 指标区域变白、文字不可见的问题。

## Mini 自动接受

- ReadyCheck 现在可以直接由可操作事件启动计时，不必等待较慢的完整状态轮询。
- 修复游戏阶段与 ReadyCheck 事件先后顺序不同导致的额外等待。
- 重复阶段事件不会重新开始 0/0.1 秒倒计时。
- LCU 事件连接短暂失败或断开后会有限退避重连；订阅成功后立即补读阶段与 ReadyCheck，覆盖握手期间漏掉的事件。
- 修复关闭自动选人时误清除自动接受截止时间的问题。
- 保留原有轮询作为断线兜底，不增加激进高频请求。

## 导航与语言

- 当前游戏分区仍会在进入时自动展开，但用户手动收起后不会被路由状态强制打开。
- 移除英雄联盟页面内部与侧栏重复的自动化、战绩、玩家中心、实时对局和客户端工具导航。
- 新增繁体中文（香港）、繁体中文（台湾）、马来语和俄语选项。
- 马来语与俄语当前标记为 Beta；核心导航和常用界面已本地化，较深页面可能回退到英文或简体中文。

## 性能证据

- 在固定的十名玩家、每次历史读取延迟 200ms 的本地确定性夹具中，旧式“等待全部分析后返回”首包为 270.9ms，新的快照首包为 0.5ms。
- 该数字只用于比较相同测试夹具下的代码路径，不代表所有电脑、区服或网络上的绝对延迟。
- 发布自动化未执行英雄联盟账号写入，也不宣称已自动跑通完整 Lobby → ReadyCheck → ChampSelect → InProgress 实机流程。

## 已确认的游戏客户端问题

- 海克斯大乱斗中偶发的 `Kiwi_Quest_Augment_Completion_Callout_Enemy` 属于 Riot 客户端未解析的 Kiwi 本地化键；MaxGameStudio 和 LeagueAkari 源码均不包含该字符串，也没有拦截游戏 HUD 渲染层的能力。本版本不会用聊天过滤器误伤用户文本。

## CS2 与 VALORANT

- CS2 与 VALORANT 本轮不做架构重写，仅随统一导航、语言和回归验证保持兼容。
- CS2 Demo 解析、灵敏度实验室、磁轴输入实验室、VALORANT 真实拉伸和准心工具延续 3.0.3 行为。

## 更新与兼容

- 旧的 League URL 继续兼容并保留查询参数。
- 更新弹窗使用面向普通用户的“修复问题 / 新增功能 / 性能与体验优化”摘要。
- 安装标识、签名公钥、更新端点与旧版迁移钩子保持不变，继续支持从 3.0.3 覆盖升级。

实际安装包、签名状态和发布状态以对应 GitHub Release 页面为准。
