# MaxGameStudio 2.5.14-rc.58 测试版

> **这是 Release Candidate，仅供测试。** 本版本不会写入正式版 `updater/latest.json`，不会向当前正式客户端推送。需要测试的用户请手动下载安装。

## 本次修正

- 安装程序、Windows 卸载项、开始菜单和桌面快捷方式统一显示为 **MaxGameStudio**。
- 覆盖旧版本时删除遗留的旧品牌桌面/开始菜单快捷方式，避免同时出现两个品牌名称。
- 构建流程会检查生成的 NSIS 脚本必须使用 `MaxGameStudio` 产品名并创建对应桌面快捷方式，否则直接终止发布。
- README 删除已经不再适合作为当前项目说明的英雄联盟上游项目字段。

## 兼容性说明

- 内部应用标识、用户数据目录和升级识别信息继续保持兼容，覆盖安装不会因此创建一套空数据。
- 安装资产仅提供 `MaxGameStudio_2.5.14-rc.58_x64-setup.exe`。
- 安装包暂未使用 Windows Authenticode 证书签名，Windows 可能显示“未知发布者”。
