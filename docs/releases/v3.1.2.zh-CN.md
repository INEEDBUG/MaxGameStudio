# MaxGameStudio 3.1.2

> `v3.1.2` 修复 Windows 存储位置、管理员启动及英雄联盟工作台切换问题。应用不再在启动时自动迁移用户数据。

## Windows 存储与安装

- 启动时优先复用已有数据位置，不会自动迁移、复制或删除旧数据；新安装可使用推荐的非系统固定磁盘，但不假定某个盘符（例如 `D:`）。
- 安装器尊重显式 `/D=` 安装目录和已有安装位置；覆盖升级保持原安装位置，不因升级流程改写用户选择。
- 静默新安装若未提供明确 `/D=`，不会静默采用系统盘路径；目录页仍允许用户确认安装位置。
- 设置中的存储面板显示数据、日志、缓存、WebView、英雄联盟运行时和临时文件的实际位置；可手动切换目录，空目录从新设置开始，也可重新选择原目录恢复使用。
- 初始化期间重复启动会安全退出；启动不再执行数据迁移，避免重复复制导致“目标目录非空”的报错。手动选择目录时仍保留防覆盖校验。
- 修复启动过程中立即退出时，将正常取消后端启动误报为“后端启动失败”的提示。

## 数据保留与边界

- 应用自有数据、后端日志、缓存、WebView 数据和英雄联盟临时文件显示其实际承载位置；新统一目录由手动切换后使用。
- 切换不复制、搬移或删除原目录。切换失败会取消本次切换并继续使用原目录；原目录也不可用时会停止启动并明确提示。
- 所选存储不可用时应明确报告错误，不静默回退到 `C:`，也不生成指向错误位置的空配置。
- Windows 系统组件、Steam/游戏文件以及 CS2、VALORANT 的游戏配置文件仍属于外部路径，不由此应用存储选择器接管。
- 管理员受保护配置位于所选卷上的独立受保护路径，与普通应用数据分开。

## 管理员工作台

- 修复管理员工作台在 UAC 前向系统盘根目录写入一次性启动脚本时出现的访问被拒绝问题；脚本改为写入所选存储的可写临时目录。
- 保持已有完整性校验与权限边界，不扩大管理员权限范围。

## 英雄联盟工作台与已知限制

- 普通权限下，进入英雄联盟页面会预热工作台；预热阶段不连接客户端、不运行游戏自动化，离开页面会取消预热。管理员启动仍需要 UAC，不使用普通预热。
- 节省内存模式在工作台显示后隐藏并销毁主 WebView，再停止后台；后台并行模式保留主窗口和后台任务。
- 修复预热进程退出后无法恢复、异步启动错误未及时显示，以及重复返回后状态未刷新的问题。
- **已知限制：首次或未预热启动仍可能需要数秒，不保证 1 秒内打开。** 本机非管理员实测：未预热重复启动约 1.8 秒，安装后的首次启动约 8 秒；预热后约 29–34 毫秒显示，节省内存模式约 85 毫秒时主窗口消失。结果受磁盘、缓存和负载影响，不代表所有设备。

## 验证与升级

- 本地验证包括前端 893 项测试、Rust 62 项测试、Clippy、Windows 安装与发布流程回归，以及实际覆盖安装、普通权限冷/热启动、返回主程序、并行保留、预热退出恢复和存储选择取消。
- 存储失败测试使用隔离目录，未为测试迁移或破坏真实用户数据。

- `v3.1.1` 用户可直接升级到 `v3.1.2`，不需要中间版本。
- 正式更新要求 Tauri updater 签名；安装包、内置后端版本和更新清单统一为 `3.1.2`，用户点击“立即更新”后才进入更新流程。
- 本说明描述本版本的实现范围；具体环境仍应按项目的安装、升级与管理员验收流程验证。
