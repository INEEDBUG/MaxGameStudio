# MaxGameStudio 3.1.2

> **正式稳定版更新说明。** `v3.1.2` 聚焦 Windows 安装路径、应用自有存储和管理员工作台启动边界。正式安装包与在线更新清单以本仓库稳定版 CI 生成并签名的文件为准。

## Windows 存储与安装

- 首次启动会询问统一的应用存储目录，之后也可在设置中修改；默认偏好可用的非系统固定磁盘，但不假定某个盘符（例如 `D:`）。
- 安装器尊重显式 `/D=` 安装目录和已有安装位置；覆盖升级保持原安装位置，不因升级流程改写用户选择。
- 静默新安装若未提供明确 `/D=`，不会静默采用系统盘路径；目录页仍允许用户确认安装位置。
- 设置中的存储面板显示当前目录、待切换目录和保留的原目录；切换在下一次启动时执行复制与校验，也可在执行前取消。

## 数据保留与边界

- 应用自有数据、后端日志、缓存、WebView 数据和英雄联盟临时文件由所选卷统一承载。
- 切换使用安全复制与校验，并保留原目录以便恢复；不要把可能已经过时的原目录盲目复制回去覆盖新数据。
- 所选存储不可用时应明确报告错误，不静默回退到 `C:`，也不生成指向错误位置的空配置。
- Windows 系统组件、Steam/游戏文件以及 CS2、VALORANT 的游戏配置文件仍属于外部路径，不由此应用存储选择器接管。
- 管理员受保护配置位于所选卷上的独立受保护路径，与普通应用数据分开。

## 管理员工作台

- 修复管理员工作台在 UAC 前向系统盘根目录写入一次性启动脚本时出现的访问被拒绝问题；脚本改为写入所选存储的可写临时目录。
- 保持已有完整性校验与权限边界，不扩大管理员权限范围。

## 升级与发布边界

- 本机已完成静默覆盖安装、旧数据复制校验、实际 WebView 存储路径、普通/管理员工作台启动，以及节省内存模式退出后恢复主程序的验证。
- 后端 1,135 项、前端 882 项、Rust 39 项测试通过；Rust 格式与 Clippy 检查、前端构建和 Windows 安装包构建通过。
- 本机现有 Windows 策略自动批准提权，本次没有更改该策略，也没有重新实测交互式取消 UAC。

- `v3.1.1` 用户可直接升级到 `v3.1.2`，不需要中间版本。
- 正式更新仍要求 Tauri updater 签名；安装包、内置后端版本和更新清单必须统一为 `3.1.2`。
- 本说明描述本版本的实现范围；具体环境仍应按项目的安装、升级与管理员验收流程验证。
