# MaxGameStudio 3.0.2

本版本集中改进大型 Demo 处理、灵敏度实验室和客户端更新说明。

## 灵敏度实验室

- 甩枪测试现在必须真实点击目标，不再以“准星碰到目标”自动结算。
- 新增欠甩、过甩、修正后点击和偏轴未命中分类。
- 结合 `0.8× / 1.0× / 1.2×` 多倍率甩枪与追踪成绩，给出提高、降低或保持游戏内灵敏度的建议。
- 横向偏移不会被误判为灵敏度快慢；点击证据和综合成绩冲突时会降低置信度并提示继续复测。
- 结果页新增点击落点倾向、详细证据和更直观的调整方向。

## Demo 性能

- 增加 Demo 快速预览，在完整解析前优先读取地图、服务器和玩家名单等概要信息。
- 完整解析改为更紧凑的数据路径，显著降低大型 Demo 的峰值内存和处理耗时。
- 优化批量解析调度，避免多个大型任务同时抢占过多内存。
- 修复首次进入 2D 回放时部分投掷物轨迹信息可能缺失的问题。

## 更新体验

- 客户端更新弹窗新增“修复问题 / 新增功能 / 性能与体验优化”三类普通用户说明。
- GitHub Release 继续保留技术细节；旧版更新清单仍可回退显示原发布说明。
- 正式发布流程现在强制要求版本化的普通用户更新摘要，避免只显示开发术语。

## 兼容性

- 灵敏度历史记录和旧客户端请求保持兼容；旧记录没有真实点击字段时会显示样本不足，不会伪造判断。
- `v2.5.17` 已撤回，建议所有用户直接升级到 `v3.0.2`。

实际安装包、签名状态和发布状态以对应 GitHub Release 页面为准。
