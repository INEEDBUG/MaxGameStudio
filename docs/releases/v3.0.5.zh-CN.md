# MaxGameStudio 3.0.5

本版本改进首次打开软件的首页，并调整普通版本更新的确认流程。

## 更新确认

- 发现新版本后，底部会同时显示“立即更新”和“暂不更新此版本”。
- 只有点击“立即更新”才会开始下载、校验、安装和重启；不会因倒计时结束而自动升级。
- 选择“暂不更新此版本”后，客户端会记住当前版本，后续自动检查不再反复提示；手动检查仍可再次查看。

## 新增首页

- 新增 MaxGameStudio 多游戏首页，展示面向普通用户的离线版本公告。
- 左侧导航新增独立的“首页”入口，不属于 CS2、英雄联盟或无畏契约分区。
- 首页提供醒目的 Bug 反馈、需求反馈 Issue 表单，以及 PR 和项目仓库入口。
- 首次打开软件不再弹出 CS2 专属上手指南；CS2 上手指南仍保留在 CS2 分区内。

## VALORANT 真拉伸配置同步

- 现有“无畏契约 → 真拉伸”应用流程会自动定位最近使用的 `Windows*\\GameUserSettings.ini`，只修改文件中已经存在的分辨率字段。
- 修改前创建完整备份，写入后重新读取验证；失败时恢复原内容与原只读属性。
- 默认将目标 CFG 设为只读，并提供解锁和恢复备份操作；检测到 VALORANT 正在运行时拒绝写入。
- 不修改全屏模式、游戏进程、Vanguard、游戏二进制或整个配置目录。Riot 更新若重建 CFG，页面会在下次检测时显示锁定或分辨率失效。

## 兼容性

- 本版本不改变 CS2、英雄联盟或 VALORANT 的既有路由；CFG 能力只补充在现有真拉伸页面内。
- 用户配置、历史数据和项目文件继续保存在独立用户数据目录中。
