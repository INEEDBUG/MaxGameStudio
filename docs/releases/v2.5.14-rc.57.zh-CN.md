# MaxGameStudio 2.5.14-rc.57 测试版

> **这是 Release Candidate，仅供测试。** 本版本不会写入正式版 `updater/latest.json`，不会向当前正式客户端推送。需要测试的用户请手动下载安装；不参与测试的用户请继续使用正式版。

## 本次更新

- 项目与桌面端用户可见品牌更名为 **MaxGameStudio**，保留原有安装标识和用户数据目录，避免覆盖安装后丢失设置、Demo 数据库或工作区数据。
- 英雄联盟实验室继续对齐 LeagueAkari 的本地 LCU 工作流，完善 Mini 面板、选人阶段、实时对局、玩家中心和战绩展示。
- Mini 面板改为深色阶段化界面，补全模式/地图状态、选人和备战席操作，并修复白色空窗口、图标损坏和旧品牌字样。
- 自动接受改为 ReadyCheck 事件驱动；零延迟时不再等待慢速轮询。继续完善赛后点赞、返回房间、交易、秒退和自动选人状态证据。
- 战绩页补全召唤师技能、装备、头像和比赛详情；实时对局改为双方十人卡片视图并支持按需展开近期战绩。
- 修复多处辅助窗口生命周期、界面渲染异常和 League 页面空状态问题。

## 测试重点与已知边界

- 请重点验证 `Lobby → Matchmaking → ReadyCheck → ChampSelect → InProgress → EndOfGame` 的完整状态链。
- 自动化会影响当前英雄联盟客户端账号或对局；只在你明确启用对应开关后执行。
- 本 RC 不代表功能已经达到正式版稳定标准。如遇问题，请记录发生阶段、客户端类型（Riot / WeGame）和截图。
- 安装包可能仍显示 Windows 未知发布者提示；这与 Tauri 更新包签名不是同一件事。

## 安装

Release 资产只保留一个 Windows 安装程序：

`MaxGameStudio_2.5.14-rc.57_x64-setup.exe`

安装前建议退出正在运行的 MaxGameStudio。覆盖安装会保留原用户数据；若需要回到稳定版，可重新运行稳定版安装包。
